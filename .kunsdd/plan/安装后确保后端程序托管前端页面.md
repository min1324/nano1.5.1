## 前端托管保障措施（新增）

后端通过 `http.Dir("./static")` 托管前端，所以安装时必须确保：

### 🪟 Windows 方案
- 安装到 `C:\Program Files\NanoCloud\`
- 目录结构：
  ```
  C:\Program Files\NanoCloud\
    ├── nano.exe          # 编译好的后端程序
    ├── static/           # 前端页面 (index.html, app.js, style.css, download.html)
    ├── config.yaml
    ├── files/
    ├── logs/
    └── run-nano.bat      # 包装脚本，先 cd 到安装目录再启动
  ```
- **服务注册**：`sc create NanoCloud binPath= "C:\Program Files\NanoCloud\run-nano.bat"` — 通过包装批处理确保工作目录正确

### 🐧 Linux 方案
- 二进制 → `/usr/local/bin/nanocloud`
- 静态资源+数据 → `/usr/local/share/nanocloud/`
  ```
  /usr/local/share/nanocloud/
    ├── static/           # 前端页面
    ├── config.yaml
    ├── files/
    └── logs/
  ```
- **systemd 服务**：`WorkingDirectory=/usr/local/share/nanocloud` 确保 `./static` 正确解析

### ✅ 安装完成后验证
```
访问 http://localhost:8080/   → 应返回 NanoCloud 前端页面
```
